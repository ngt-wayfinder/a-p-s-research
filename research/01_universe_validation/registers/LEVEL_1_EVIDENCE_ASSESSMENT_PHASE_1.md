# Level 1 evidence-based assessment — phase 1 (2026-10-15)

**Scope:** 316 provisional operating-company candidates. **Source:** existing primary evidence ledger (1,291 records), screening register and 316 unresolved-exception records. **Decision:** 316 REVIEW_PENDING; 0 ELIGIBLE; 0 QUARANTINED.

## Primary evidence assessment and scope limitations

The existing ledger records issuer legal identity, name history, issuer-authored ASX filings and other primary documents. These are *field-level evidence*, not full gate sign-offs. Every candidate has an unresolved historical-continuity review and a dated trading-status gap in the authoritative evidence matrix. The unresolved exceptions file contains company-specific remaining facts and resolution steps. No source should be treated as proof of trading solely because an ABN is active or an ASX filing exists.
